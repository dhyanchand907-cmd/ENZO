# 🎌 Award-Winning Website

An immersive, anime-inspired interactive website built with **React.js, GSAP, and Tailwind CSS**, featuring modern animations, cinematic video transitions, and interactive UI effects.

> **Note:** This project is inspired by an Awwwards-style website tutorial from **JavaScript Mastery**. The original design concept and inspiration belong to their respective creators. This project was created for **educational and learning purposes**.

---

## ✨ Features

* 🎬 Smooth video transitions
* 🌀 Scroll-based animations
* 🔷 Clip-path and geometric transitions
* 🖱️ 3D hover effects
* 🎞️ Interactive anime-inspired visuals and videos
* 📱 Fully responsive design
* ⚛️ Reusable React components
* 🎨 Modern and immersive UI/UX
* ⚡ Smooth animations powered by GSAP

---

## 🛠️ Tech Stack

* **React.js** — Frontend library
* **GSAP** — Advanced animations
* **Tailwind CSS** — Styling and responsive design
* **JavaScript** — Logic and interactions
* **Vite** — Development environment

---

## 🎯 About the Project

The goal of this project was to explore how modern frontend technologies can be used to create an engaging and cinematic web experience.

I followed **JavaScript Mastery's** tutorial as a learning foundation and then customized the project with:

* Different anime-inspired videos
* New visual content

* My own creative direction

This project helped me understand how **animation, interaction, and visual storytelling** can make a website feel more dynamic.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ProgrammingWithNick/award-winning-website.git
```

### 2. Navigate to the project

```bash
cd award-winning-website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the project.
